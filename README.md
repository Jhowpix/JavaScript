# JavaScript

Repositório destinado ao estudo e à prática de **JavaScript**, reunindo exercícios, conteúdos e aplicações desenvolvidas ao longo do processo de aprendizagem.

O objetivo é registrar de forma organizada a evolução dos conhecimentos relacionados à linguagem e à sua utilização no desenvolvimento web.

## Objetivo

Consolidar os fundamentos de JavaScript por meio de estudo teórico, exercícios práticos e pequenos projetos.

O repositório também serve como registro da evolução no aprendizado da linguagem, desde os conceitos fundamentais até recursos mais avançados.

## Conteúdos estudados

Entre os conteúdos trabalhados neste repositório estão:

* Fundamentos de JavaScript
* Variáveis e tipos de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição
* Funções
* Arrays
* Objetos
* Módulos
* Manipulação do DOM
* Eventos
* Exercícios práticos
* Desenvolvimento de pequenos projetos

## Processo de aprendizagem

O estudo é realizado de forma progressiva, utilizando exercícios e aplicações práticas para reforçar os conceitos apresentados durante os estudos.

A organização dos arquivos acompanha diferentes etapas do aprendizado, permitindo consultar e revisar conteúdos já estudados.

## Próximas etapas

O aprendizado de JavaScript faz parte de uma formação mais ampla em programação.

Após a consolidação dos fundamentos, a sequência de estudos inclui:

* Python
* SQL
* Estruturas e manipulação de dados
* Pandas
* Análise de dados
* Desenvolvimento de projetos práticos

## Progresso

Este repositório permanece em desenvolvimento e será atualizado conforme novos conteúdos, exercícios e projetos forem realizados.

O objetivo é manter um registro consistente da evolução técnica e dos conhecimentos adquiridos ao longo dos estudos.

JavaScript

Repositório destinado ao estudo e à prática de JavaScript, reunindo exercícios, conteúdos e aplicações desenvolvidas ao longo do processo de aprendizagem.

O objetivo é registrar de forma organizada a evolução dos conhecimentos relacionados à linguagem e à sua utilização no desenvolvimento web.

Objetivo

Consolidar os fundamentos de JavaScript por meio de estudo teórico, exercícios práticos e pequenos projetos.

O repositório também serve como registro da evolução no aprendizado da linguagem, desde os conceitos fundamentais até recursos mais avançados.
